Keep the Stremio profile used for approval active. These private install links are revealed only after provider import; do not share them or apply them across profiles.

Before playback
  1. In Stremio, set Settings > Playback > Default player to External player.
  2. Select Jumpgate when Android asks. Use Just once while testing. Always can affect matching launches from other apps, and a different stream scheme may ask again.
Android skipped the chooser?

Clear only the other player's Open by default or Set as default selection. Toggling Stremio's player setting does not clear Android's remembered external app. Do not clear Stremio app data or sign out.
